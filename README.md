# VenoZ downloads

Android builds of **VenoZ**, a small Whiteout Survival gift-code app made by **n1_ozzy**.

1. Open the latest release below and download the `.apk`.
2. Open it on the phone and allow installs from that source once.

From version 3.2.0 on, the app checks this page by itself and shows an **Update** button when a newer
build is out. Your player list and history stay after updating.

The app's code is private; this repository only holds the installable files.
